Dumb Patrick Inputs

Правила заполнения

Правила применяются сверху вниз. Первое совпавшее захватывает поле. Порядок меняется кнопками ▲ ▼. Правило можно положить в папку через дропдаун в его настройках.

Получение данных о клиенте из debug

Считывает key-value данные из debug-таблицы на странице и показывает их в попапе расширения. Укажите URL-подстроку и родительский селектор. Чтобы получить список полей, откройте нужную страницу и нажмите «🔍 Сканировать» в попапе расширения (возле закладок).

Copy Trading — Работа с API

Считывает ответ API со списком стратегий CopyFX и показывает таблицу трейдеров в попапе. Кнопка «Получить трейдеров» доступна на страницах, совпадающих по URL-паттерну.

User-Agent по URL

Автоматическая подмена User-Agent на сайтах, совпадающих по URL. Работает без хоткеев — расширение само применяет нужный агент при переходе на страницу.

Специальные вставки

⚠ Раздел временно недоступен — находится в разработке.

Умные инкременторы

Именованный счётчик с префиксом и ветвлением по URL-домену. Используйте в шаблонах как {{seq:имя}}. При каждом заполнении значение увеличивается на 1. Если URL страницы совпадает с regex одного из доменов, к значению добавляется суффикс (например B). Regex проверяется без учёта регистра.

Пользовательские списки слов

Создайте свои списки слов для использования в шаблонах через {{list:имя}}. При каждом заполнении подставляется случайное слово из списка.

Версии настроек

Ручные версии (макс. 20) — при переполнении удаляется самая старая без звёздочки. Автоматические версии (макс. 10) создаются при сохранении правил и хранятся отдельно.

Журнал действий

Глобальные горячие клавиши (Chrome)

  • Ctrl+Shift+F — заполнить все поля по правилам
  • Ctrl+Shift+1 — выполнить специальную вставку для текущего URL

Chrome ограничивает 4 глобальных шорткея. Изменить их: chrome://extensions/shortcuts

Свои горячие клавиши (внутри страницы)

Работают, когда фокус на веб-странице (не в браузерных элементах). Можно задать любое сочетание клавиш и привязать его к действию: заполнить все поля / выполнить вставку по URL / выполнить конкретную вставку. Количество не ограничено.

Режим отладки

Включает подробное логирование в консоль браузера (DevTools → Console). Полезно для диагностики, почему правило не матчит поле или какой шаблон сгенерировался.

Глобальные счётчики {{counter}} / {{increment}}

Это обычные счётчики без ветвления. Умные инкременторы — на отдельной вкладке.

⚠ Опасная зона: сбросить все настройки

Это действие необратимо удалит все правила, папки, вставки, инкременторы, списки слов и счётчики. Версии (снапшоты) сохранятся. Сначала сделайте экспорт JSON.

О приложении

Dumb Patrick Inputs — расширение для быстрого заполнения форм на любых сайтах. URL-таргетинг, шаблоны с динамикой, папки-коллекции, специальные вставки и умные инкременторы.

Версия: — · Хранилище: chrome.storage.local

Основные возможности

  • Правила заполнения — плоский список с папками (как коллекции в Postman). Каждое правило со своими URL-паттернами и условиями. AND между условиями по умолчанию; смешанная AND/OR-логика по флажку.
  • Папки — цветные группы для организации правил. Правило можно перекинуть в любую папку.
  • История правил — последние 5 редакций каждого правила с возможностью отката.
  • Специальные вставки — одна вставка на URL. Шорткей очищает целевой input и вставляет значение. Опциональная кнопка-триггер для двухшаговых полей.
  • Умные инкременторы — счётчик с префиксом и ветвлением по URL (main / branch). История последних значений.
  • Версии — снапшоты состояния, экспорт каждой версии в JSON.
  • Импорт/Экспорт — полный state в JSON, стратегии Replace / Merge.
  • Анализатор HTML — вставь outerHTML → автоматически подберётся селектор и предложатся шаблоны.

Приоритет правил

Правила применяются сверху вниз внутри общего списка. Первое совпавшее захватывает поле. Порядок меняется кнопками ▲ ▼. Папки — только визуальная группировка, они не влияют на приоритет.

AND/OR между условиями

По умолчанию все условия правила соединяются AND. Включи флажок «Использовать смешанную AND/OR-логику» на правиле — между каждыми двумя соседними условиями появится выбор AND/OR. Вычисляется слева направо, без precedence — управляй порядком условий сам.

Установка

chrome://extensions/ → «Режим разработчика» → «Загрузить распакованное расширение» → выбрать папку.

Новая вставка из HTML

Из URL автоматически вытянется host+path. Можно поправить перед анализом.

Если целевой input появляется только после клика по кнопке — вставьте её outerHTML сюда. При заполнении расширение сначала кликнет по кнопке, дождётся и уже потом искать целевой input. Если input уже виден без клика — оставьте пустым.

В DevTools: правой кнопкой по элементу → Copy → Copy outerHTML.
