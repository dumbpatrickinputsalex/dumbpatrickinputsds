# Dumb Patrick Inputs

Расширение Chrome для быстрого заполнения форм. Правила с AND/OR-логикой
матчинга и URL-таргетингом, шаблоны со статикой и динамикой, специальные
вставки, умные инкременторы и полноценный импорт/экспорт настроек.

## Установка (без Chrome Web Store)

1. Откройте `chrome://extensions/`
2. Включите «Режим разработчика» справа сверху.
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `formfiller-extension`.

Иконка появится в панели. Кликните — увидите popup.

## Быстрый старт

- `Ctrl+Shift+F` — заполнить все поля активной страницы правилами текущего профиля.
- `Ctrl+Shift+1` — выполнить специальную вставку для текущего URL (одна на URL).
- Правая кнопка → «Параметры» или кнопка «Настройки» в popup — полная страница настроек.

Изменить шорткеи: `chrome://extensions/shortcuts`.

## Модель данных

```
state
├── folders[]                   ← папки-коллекции с иконкой
│   └── { id, name, icon }
├── rules[]                     ← плоский список; порядок = приоритет матчинга
│   ├── name, folderId          ← folderId=null → «Без папки»
│   ├── enabled, collapsed
│   ├── targets[]               ← input | textarea | select | checkbox | radio
│   ├── urlPatterns[]           ← регулярки; пусто = глобально
│   ├── template                ← Mustache-шаблон
│   ├── match
│   │   ├── customLogic         ← false: все AND; true: показать connectors
│   │   └── conditions[]        ← каждое условие + connector (AND/OR) к предыдущему
│   ├── createdAt, updatedAt
│   └── history[]               ← последние 5 редакций для отката
├── specialInsertions[]         ← { urlPattern, targetSelector, triggerSelector, valueTemplate }
├── smartCounters[]             ← умные инкременторы {{seq:name}}
├── snapshots[]                 ← версии state
└── counters { имя → n }        ← простые {{counter}}
```

**Порядок правил** сохраняется автоматически в приоритетной последовательности:
сначала правила без папки, затем группы по порядку папок. Внутри папки — тот
порядок, в котором ты их разместил кнопками ▲ ▼.

## Синтаксис шаблонов

Обычный текст со вставками `{{token}}` или `{{token:параметр:параметр}}`.

| Токен | Пример | Что делает |
|---|---|---|
| `{{name.first}}` | Александр | Случайное имя |
| `{{name.last}}` | Иванов | Случайная фамилия |
| `{{name.full}}` | Мария Петрова | Полное имя |
| `{{email}}` / `{{email:mail.ru}}` | ivan.petrov42@mail.ru | Email; можно домен |
| `{{phone}}` / `{{phone:+7##########}}` | +7 (912) 345-67-89 | `#` — случайная цифра |
| `{{company}}` | ООО Ромашка | Компания |
| `{{city}}` / `{{street}}` / `{{address}}` | Казань / ул. Ленина, д. 5 | |
| `{{number:1:100}}` | 42 | Число в диапазоне |
| `{{date:2020-01-01:2024-12-31:yyyy-MM-dd}}` | 2022-07-14 | Дата в диапазоне и формате |
| `{{now:yyyyMMdd_HHmmss}}` | 20260806_141530 | Текущая дата/время |
| `{{uuid}}` | 7b3e... | UUID v4 |
| `{{lorem.words:5}}` | lorem ipsum dolor sit amet | |
| `{{lorem.sentence:8}}` / `{{lorem.paragraph:3}}` | ... | |
| `{{pick:кот\|пёс\|хомяк}}` | пёс | Случайное из списка (разделитель `\|`) |
| `{{counter}}` / `{{counter:orderId}}` | 1, 2, 3… | Инкремент, глобальный или именованный |
| `{{increment:reg:1000:5}}` | 1000, 1005… | Счётчик со стартом и шагом |
| `{{regex:[A-Z]{3}-\d{4}}}` | ABC-1234 | Строка по регулярке |

Всё внутри шаблона можно комбинировать:

```
test_{{name.first}}_{{now:yyyyMMdd}}_{{regex:[a-z]{5}}}@{{pick:mail.ru|gmail.com}}
```

## Матчинг полей

Правило совпадает с элементом, если ЛОГИКА (AND / OR) над списком условий
возвращает true. Условия трёх типов:

- **Селектор** — CSS-селектор; в редакторе есть кнопка 🎯 «выбрать» —
  включает overlay на активной вкладке, где кликом по элементу
  получаешь уникальный селектор.
- **Атрибут** — сравнение значения `id / name / class / placeholder / label / type / data-*`
  с паттерном. Флажок `regex` — трактовать как регулярку.
- **Порядковый №** — n-ное подходящее поле в форме (1-based).

Если правило целится в чекбокс/радио, шаблон интерпретируется как булев:
`true|1|yes|on|checked` → отметить, иначе снять отметку.

Для `<select>` шаблон ищет `<option>` по value или тексту.

## Специальные вставки

Отдельная страница со списком вставок. Одна вставка на URL-паттерн:

```
{
  urlPattern: "example\\.com/edit",
  targetSelector: "#login",
  triggerSelector: "button.add-value",   // опционально
  triggerWait: 300,                       // мс, ожидание после клика
  valueTemplate: "test_{{counter:special}}"
}
```

Когда ты на подходящей странице и жмёшь `Ctrl+Shift+1`:

1. Расширение ищет `targetSelector`. Если поле уже в DOM — сразу заполняет.
2. Если поля нет и задан `triggerSelector` — кликает по этой кнопке и ждёт
   до `triggerWait + 500ms` появления цели.
3. Как только цель появилась (или если была изначально) — очищает и вставляет
   значение.

Так работают формы, где поле скрыто за кнопкой «Добавить» / «Редактировать».
Оба сценария — «кнопка ещё не нажата» и «кнопка уже нажата, инпут виден» —
обрабатываются одной вставкой.

Работает только для `<input>` и `<textarea>`.

## Бэкап

Вкладка «Импорт / Экспорт»:

- Кнопка **Скачать JSON** — весь state в файл.
- Кнопка **Загрузить JSON** — режим `replace` полностью заменяет, `merge`
  дополняет правила, вставки, инкременторы и списки слов.
- Кнопка **Сбросить всё** — удаляет настройки, но сохраняет версии (снапшоты).

Данные хранятся в `chrome.storage.local` (~10 МБ квота). Между устройствами
не синхронизируются — переносите через JSON.

## Совместимость с фреймворками

Значения устанавливаются через нативный setter `HTMLInputElement.prototype.value`
и сопровождаются событиями `input`, `change`, `blur`. React / Vue / Angular
корректно ловят изменения.

## Ограничения текущей версии

- Chrome позволяет максимум 4 глобальных шортката. Задействованы 2.
- Regex-генератор упрощённый: поддержаны `[набор]`, `\d \w \s`, кванторы
  `{n}` и `{min,max}`, точка, литералы, простые группы `(a|b)`. Ссылки
  назад и жадные/ленивые нюансы игнорируются.
- Хранилище — только `local`; синхронизация браузеров через файл-бэкап.
- iframe формы не заполняются (`all_frames: false`).

## Быстрое добавление вставки из HTML

В popup — кнопка «＋ Добавить вставку из HTML». Открывает страницу настроек
с модалкой:

1. URL текущей вкладки уже подставлен.
2. Из DevTools скопируйте `outerHTML` целевого элемента и вставьте в поле.
3. Кнопка «Анализировать» — расширение выбирает самые стабильные атрибуты
   (`id` → `data-testid` → `name` → `aria-label` → `placeholder` → устойчивые классы),
   формирует селектор и определяет категорию поля.
4. По категории (email, phone, card, cvv, expiry, currency, date, checkbox,
   select и т.д.) предлагает варианты шаблонов — кликом выбираете нужный
   или пишете свой.
5. «Сохранить» — вставка попадает в список.

## Версии настроек

Вкладка «Версии» — история снапшотов состояния:

- **Сохранить текущую версию** — снимок всех правил, вставок, инкременторов и списков слов.
- ⭐ **Звёздочка** — защита от автоудаления.
- Лимит 20 версий. При переполнении удаляется первый снапшот **без звёздочки**.
- Каждую версию можно **скачать JSON** — файл готов к передаче другому
  пользователю (у него импортируется через обычный «Загрузить JSON»).
- **Восстановить** — заменяет текущее состояние снапшотом (список версий
  сохраняется).

## Сортировка правил

Кнопками ▲ ▼ на свёрнутой карточке правила меняете его позицию.
Верхнее правило имеет высший приоритет: если два правила подходят к одному
полю, применяется то, что выше.

## Умные инкременторы

Отдельная вкладка «Инкременторы». Именованный счётчик с префиксом и
опциональной логикой ветвления по URL. Используется в шаблонах как
`{{seq:имя}}`.

Пример конфига:

```
name:          customerId
prefix:        Szv
width:         5              (ведущие нули)
current:       355
branchRegex:   www-\d+        (когда URL совпадает — считаем «веткой»)
branchSuffix:  B
```

Каждое использование `{{seq:customerId}}`:

- на URL `https://app.com/www-1234/x` → `Szv00356B` (совпало → +suffix)
- на URL `https://app.com/customers` → `Szv00357` (не совпало → без suffix)
- следующий вызов на любом URL → инкремент от предыдущего значения

История последних 10 значений с URL и временем — в раскрывающейся секции
на карточке. Текущее значение можно изменить руками в любой момент —
дальнейший отсчёт пойдёт от него.

## Табы настроек

- **Правила** — правила заполнения с папками (fill-all).
- **Спец. вставки** — по одной вставке на URL для точечного вставления значения.
- **Инкременторы** — умные счётчики с ветвлением по URL.
- **Версии** — история снапшотов (макс. 20, звёздочка защищает от автоудаления).
- **Экспорт / Импорт** — JSON-файл всего state.
- **Настройки** — шорткеи, глобальные счётчики, списки слов, опасная зона (сброс без удаления версий).
- **О приложении** — справка по токенам и общая инфа.

## Развитие

Идеи следующих итераций: undo последнего заполнения, условная логика в
шаблонах (`{{if:...}}`), матчинг по DOM (не только URL),
поддержка iframe, глобальный переключатель на паузу.
